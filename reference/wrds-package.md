# wrds: Access 'Wharton Research Data Services' ('WRDS')

Provides simple functions for accessing data from 'Wharton Research Data
Services' ('WRDS'), a widely used financial database in academic
research. Includes credential management via the system keyring,
database tools, and functions for downloading generic tables,
'Compustat' fundamentals, and linking tables.
